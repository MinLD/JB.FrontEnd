# src

Đây là folder chứa mã nguồn chính của ứng dụng, chia theo trách nhiệm: trang, giao diện, giao tiếp API và logic dùng chung. Alias `@/` trỏ vào folder này.

| Folder | Chứa gì |
| --- | --- |
| [app](./app/README.md) | Trang, layout và API Next.js |
| [components](./components/README.md) | Thành phần giao diện |
| [services](./services/README.md) | Gọi API và xử lý phiên |
| [providers](./providers/README.md) | State dùng chung |
| [config](./config/README.md) | Cấu hình và nội dung tĩnh |
| [lib](./lib/README.md) | Validation và logic dùng chung |
| [types](./types/README.md) | Kiểu dữ liệu |
| [utils](./utils/README.md) | Hàm tiện ích |
